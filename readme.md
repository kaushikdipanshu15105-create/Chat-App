# ChatApp

ChatApp is a full-stack, real-time messaging application built using the MERN stack (MongoDB, Express.js, React.js, Node.js) and Socket.IO for instant, bidirectional web communication.

## Project Structure

The project is divided into two primary directories:

- **client:** React.js frontend built with Vite and Tailwind CSS.
- **server:** Node.js backend using Express, Mongoose, and Socket.IO for real-time connection handling.

## Features

- **Real-Time Messaging:** Instant messaging powered by Socket.IO sockets.
- **User Authentication:** Secure signup and login flow with JWT and HTTP-only cookie management.
- **Database Integration:** Persistent storage for user profiles and chat histories using MongoDB Atlas.
- **Dynamic Timestamps:** Automatic message timestamps formatted to the user's local timezone.
- **Responsive UI:** Clean, modern interface designed with Tailwind CSS.

## Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS, Socket.io-client
- **Backend:** Node.js, Express.js, Socket.IO, Mongoose
- **Database:** MongoDB Atlas
- **Authentication:** JSON Web Tokens (JWT), Cookie-Parser
